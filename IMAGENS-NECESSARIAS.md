## 💡 **DICAS PARA AS FOTOS**

### 📷 **Como tirar boas fotos:**
1. Use **luz natural** sempre que possível
2. **Fundo neutro** ou clean (branco, cinza claro)
3. Foque nos **detalhes** das flores de açúcar
4. Mostre **diferentes ângulos** dos bolos
5. Fotos em **alta resolução** (sem zoom digital)

### 🎨 **Edição básica:**
1. Ajuste brilho e contraste
2. Aumente um pouco a saturação (cores vivas)
3. Recorte para as dimensões corretas
4. Salve em qualidade alta (80-90%)

### ⚙️ **Otimização:**
- Use [TinyPNG.com](https://tinypng.com/) para comprimir
- Mantenha cada imagem abaixo de 500KB
- Formato: **JPG** para fotos, **PNG** para logo

## ❓ **E SE EU NÃO TIVER TODAS AS FOTOS AGORA?**

**Solução temporária:**
1. Use fotos de placeholder do Instagram
2. Baixe algumas fotos do seu Instagram @claudycakes
3. Redimensione para as dimensões certas
4. Coloque com os nomes corretos
5. Substitua depois por fotos profissionais

**Ferramentas para redimensionar:**
- [iLoveIMG.com](https://www.iloveimg.com/pt/redimensionar-imagem)
- [Photopea.com](https://www.photopea.com/) (Photoshop online grátis)
- Aplicativo de fotos do Windows/Mac
