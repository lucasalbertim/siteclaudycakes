## 📋 **PRÓXIMOS PASSOS PARA VOCÊ**

### **1. Instalar Node.js** (se ainda não tiver)
- Download: https://nodejs.org/
- Instale a versão LTS (recomendada)

### **2. Instalar dependências do projeto**
Abra o PowerShell na pasta do projeto e execute:
```powershell
npm install
```

### **3. Adicionar suas imagens**
Consulte o arquivo **`IMAGENS-NECESSARIAS.md`** que lista:
- 21 imagens necessárias
- Dimensões de cada uma
- Onde colocar cada arquivo

**Imagens obrigatórias:**
- Logo (500x500px)
- Favicon (32x32px)
- Hero background (1920x1080px)
- Foto da confeiteira (800x1000px)
- 12 fotos de bolos para galeria (800x800px cada)
- E mais algumas...

### **4. Personalizar textos**
No arquivo **`src/views/About.vue`** (linha ~32):
- Substitua o texto placeholder pela história REAL da confeitaria
- Conte sua trajetória
- Fale sobre sua paixão

### **5. Testar o site**
Execute no PowerShell:
```powershell
npm run dev
```
O site abrirá em: `http://localhost:3000`

### **6. Integrar Instagram Feed (opcional)**
Use uma dessas ferramentas:
- **EmbedSocial** (embedsocial.com)
- **SnapWidget** (snapwidget.com)
- **Juicer** (juicer.io)

Cole o código gerado em `src/views/Portfolio.vue`

### **7. Publicar o site**
Opções gratuitas:
- **Vercel** (recomendado) - vercel.com
- **Netlify** - netlify.com
- **GitHub Pages** - pages.github.com
